# 🌍 World Bank Demographic Trends Analysis

## 📊 Project Overview

This project explores **global demographic trends** by analyzing key indicators such as:

- **Birth Rate** (per 1,000 people)
- **Internet Usage** (% of population)
- **Fertility Rate** (children per woman)
- **Life Expectancy** (years)

The analysis is grouped by **Country Income Groups** and **Geographic Regions**, with a historical comparison between **1960** and **2013**. The goal is to support data-driven policy planning and uncover insights relevant to global development initiatives.

## 🔍 Key Insights

- There is a **strong negative correlation** between birth rate and internet usage.
- **High-income** and **digitally connected countries** tend to have **lower fertility** and **higher life expectancy**.
- From 1960 to 2013, **global fertility declined** while **life expectancy improved** significantly
